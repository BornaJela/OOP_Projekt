[HR] # OOP_Projekt - Flappy Bird klon
Flappy Bird igra napravljena uz C++ i SFML 2.5.1 biblioteke. Igra se pokreće pritiskom na tipku "ENTER", a potom da bi održavali pticu u zraku, potrebno je pritiskati tipku "SPACE".
Nakon što igra završi, imamo opciju za započeti ispočetka "Restart game" koju možemo pokrenuti sa klikom miša.

[ENG] # OOP_Project - Flappy Bird clone
Flappy Bird game made with C++ and SFML 2.5.1 libraries. The game is started by pressing the "ENTER" key, and then to keep the bird in the air, you need to press the "SPACE" key. After the game ends, we have the option to start from the beginning "Restart game" which we can start with a mouse click.
